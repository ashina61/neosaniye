# NeoSaniye — Venüs Short

İlk sıfırdan Remotion Shorts konusu: **Venüs'te bir gün neden bir yıldan uzun?**

## Çalıştırma

```bash
npm install
npm run audio
npm start
```

## Render

```bash
npm run build:short
```

GitHub Actions içindeki **Render Venus Short** workflow'u manuel çalıştırıldığında Türkçe sesi, zamanlama verisini, müziği ve farklı SFX katmanlarını üretir; ardından MP4 artifact oluşturur.
